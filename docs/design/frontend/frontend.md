# Getting into the game

_Resolution: direction_

You launch and you are one click from playing. The menu is made of the same
material as the game, so nothing about the transition feels like leaving one
application for another.

## What exists before play

A title, a way to start, a way to join someone else, and a way to leave. Options
where a player needs them, especially the
[accessibility ones](../pillars.md), which belong here rather than buried.

The menu is built from [the cell grammar](../world/cells.md) like everything
else. There is no separate interface art.

## Sessions

Starting play means either hosting or joining, which makes the frontend the
first place [multiplayer](../multiplayer/multiplayer.md) becomes visible to a
player.

Details of layout and controls belong to [the menu](menu.md).

## Open

Whether there is a persistent character selected before play or whether a
session creates one.
