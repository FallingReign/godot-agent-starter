# Menu

_Resolution: direction_

The first screen is quiet. A title, a short list of things you can do, and the
one you probably want is already highlighted.

## Layout

Options are a single vertical list, keyboard and controller navigable, with the
current selection carrying a structured outline rather than only a colour
change. That is the same selection treatment
[interface panels](../ui/panels.md) use, so the convention is learned once.

Composed of stamps like any other screen, not a special layout system. See
[getting into the game](frontend.md) for what the menu is for.

## Open

Whether options are a separate screen or expand in place.
