# Interface

_Resolution: settled_

Opening a menu feels like rearranging the same material the world is made of,
not like a layer arriving on top of it. An item in a panel is the item you saw
on the ground.

## Built from the world

The interface is composed from [the cell grammar](../world/cells.md). Panels,
borders, cursors, bars and icons are stamps, and text appears where language is
genuinely needed.

There is no second visual system for interface, which is what makes an item's
identity survive the trip from ground to panel. Continuity is the point rather
than a stylistic preference.

## Readability governs

Committing to the grammar does not licence an unusable interface. Grouping,
spacing, selection feedback and contrast all take precedence over visual
consistency where they conflict, because an interface that is pretty and
unreadable has failed at its only job.

Nothing essential relies on hue. A state carries a shape or position difference
as well, so the interface survives a palette swap and a colour-blind player.

Small compositions used as symbols are [icons](icons.md). Larger arrangements
are [panels](panels.md).
