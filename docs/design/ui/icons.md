# Icons

_Resolution: direction_

An icon looks like a small version of the thing it means, not a symbol you had
to learn. A door icon is made from the forms a door is made from.

## Derivation, not invention

An icon is a simplified composition of the thing it refers to, produced by
removing detail rather than by designing a separate mark. A healing icon uses
forms visible in healing effects; a location marker carries the landmark's
silhouette.

That keeps the icon set from becoming a private alphabet, which is the
[recognition pillar](../pillars.md) applied at the smallest scale the game
draws at.

Icons obey the same [minimum cell size](panels.md) constraint as anything else
read at a fixed distance, and sit inside [the interface](ui.md).

## Open

Whether some abstract states, ownership or quest relevance for instance, have no
derivable form and need a learned mark after all.
