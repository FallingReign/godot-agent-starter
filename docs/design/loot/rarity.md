# Rarity

_Resolution: direction_

A rare thing looks rare from across the room, and it does not look rare by being
brighter.

## How quality reads

Rarity is carried by structure rather than by colour intensity. Additional
layers, a distinct framing, asymmetry in the composition, an unusual shape from
the set, a slow animated accent. Colour may accompany those but never carries
the information alone, because [the accessibility pillar](../pillars.md) would
otherwise fail exactly where it matters most.

Complexity is not the same as quality. A rare item that is merely busier is
harder to read, which trades a pillar for a signal.

The composition itself belongs to [loot](loot.md); this section only covers how
quality is expressed within it.
