# Reference rules

Detail moved out of `AGENTS.md` to keep that file to a single read. Load this only
when you need the specific section.

## Full ownership table

Ownership is by **operation**, not file extension. A scene you write is verified by the
engine itself (`resources` stage), so scenes are not off limits.

| You own | Rules |
| --- | --- |
| `*.gd`, `*.gdshader` | Freely |
| `*.tscn`, `*.tres` | Yes, subject to `SCENES.md` |
| Asset source files | Drop in, then `kit verify --stage import` |
| `tests/**`, `docs/**`, `*.md` | Freely |
| Level/content data in the project's own format | Freely, it is code |

| Never touch | Why |
| --- | --- |
| `*.import` | Machine-generated by the importer. Commit them, never hand-edit |
| `*.uid` | Machine-generated. `git mv` alongside the script, never edit |
| `check.py`, `arch.py`, `sanitise.py`, `gate.rules.json` | Protected gate implementation, hash-checked by `integrity`. Editing it to make a failure disappear is prohibited |
| `arch.rules.json` | Human-reviewed architecture policy. Its drift is reported rather than hash-blocked because legitimate module work changes it |
| `<game_root>/tools/validate_resources.gd` | Gate logic, but not hash-pinned because `gdformat` owns its canonical formatting. Do not change its behaviour |
| `<game_root>/project.godot` and especially its `[debug]` block | Engine/human-owned configuration. Drift is reported; lowering a warning is rejected |
| `export_presets.cfg` | Human-authored |
| `<game_root>/addons/**` | Third-party |
| `.gate.sha256` | Only `kit integrity accept` writes it, and only a human may run that after reviewing the protected-file diff |
| `.github/copilot-instructions.md` | Provider-governance bridge. Game builders must not edit the instructions that make Copilot load the shared contract |

## Permanently human-only

- **Graph-authored resources**: AnimationTree state machines, TileSet terrain peering
  bits, visual shader graphs. Their text form is machine-generated with no meaningful
  authoring semantics, so editing it is guessing.
- **Bake artefacts**: LightmapGI and occlusion culling are not exposed to scripting. If
  you rewrite a scene, preserve every reference to a baked resource. Dropping one makes
  the scene render unlit or unculled with no error.
- **Export presets and export template installation.** No CLI path exists.
- **Device testing**: touch targets, thermals, battery.
- **Taste**: layout, anchors, composition, whether it looks right.

## Concurrency

Godot does not lock files and does not watch the filesystem; it polls on focus. An open
scene in the editor holds an in-memory copy that overwrites the file on the next save,
with no warning and no undo entry.

**So: the human closes the editor, or you work in a `git worktree`.** Never assume both
are safe at once.

Do not run `git pull`, `git rebase` or `git checkout <branch>` while the editor may be
open. Branch switches trigger the overwrite bug and full reimport storms.

When moving a script, `git mv` the `.gd` **and** its `.gd.uid` in the same commit.

## Why config is injected, not global

1. A system reaching out to a global is hidden coupling. Config should flow in, the way
   an ECS passes a singleton component to a system.
2. Every global lookup inside a hot loop becomes a boundary crossing if that loop is
   later ported to GDExtension. Flat data copies once and is read at native speed.
3. Tests construct a config with different values instead of mutating global state.

Keep config to typed primitives: `int`, `float`, `bool`, `String`, `Vector2/3`, `Color`.
No object arrays, no `Node` or `Resource` references. That shape maps directly onto a
C++ struct or an ECS component, so a later port is mechanical.

Magic numbers scattered through logic are a review problem, not a gate problem. If a
value is tuned rather than derived, it belongs in config.

## Level and content data (if applicable)

If levels are a custom data format rather than authored `.tscn`, three rules apply from
the first commit because they cannot be retrofitted:

- **Versioned.** Every save writes a version; every load checks it. User-generated
  content must keep loading after the format changes.
- **Data only.** No script paths, no expressions, no callables. Content from other
  players is untrusted input.
- **One validator.** The same `validate()` runs in the editor, the loader and the gate,
  so malformed content fails in CI rather than on a player's machine.

If the project needs this boundary, keep its typed format and validator under
`scripts/data/` inside the configured game root. Do not ship a sample format merely
because the kit supports one; persistence shape must come from the project's own
direction and content-pipeline decision.

## Full style order

Within a file: `class_name`, `extends`, docstring, signals, enums, constants, `@export`,
public vars, private vars, `_init`, `_ready`, other virtuals, public methods, private
methods. Tabs for indentation. `class_name` on anything reused across files.

## All banned Godot 3 idioms

Several **parse cleanly in Godot 4 and fail silently at runtime**, so no tool catches
them. The gate greps for all of these.

| Never write | Write instead |
| --- | --- |
| `connect("pressed", self, "_on_pressed")` | `button.pressed.connect(_on_pressed)` |
| `emit_signal("died")` | `died.emit()` |
| `yield(get_tree(), "idle_frame")` | `await get_tree().process_frame` |
| `export var x` | `@export var x: int = 0` |
| `onready var n = $Node` | `@onready var n: Node = $Node` |
| `tool` | `@tool` |
| `KinematicBody` / `KinematicBody2D` | `CharacterBody3D` / `CharacterBody2D` |
| `Spatial` | `Node3D` |
| `Spatial.translation` | `Node3D.position` |
| `move_and_slide(velocity, UP)` | set `velocity`, then `move_and_slide()` |
| `OS.get_ticks_msec()` | `Time.get_ticks_msec()` |
| `PoolStringArray` | `PackedStringArray` |
| `.instance()` | `.instantiate()` |
| `File.new()` / `Directory.new()` | `FileAccess` / `DirAccess` |
| `rand_range()` | `randf_range()` / `randi_range()` |

The four-argument `connect` form is the worst: it parses, it never fires, and neither
`gdlint` nor `--check-only` reports it.

## Multiplayer conventions (if applicable)

Skip entirely in a single-player project, and delete the `net`-tagged rules from
`gate.rules.json`.

- Authority is explicit. Every `@rpc` declares its mode; no bare `@rpc`.
- Use `@rpc("any_peer", "call_local", "reliable")` with all arguments spelled out.
- Validate sender with `multiplayer.get_remote_sender_id()` on anything `any_peer`.
- Simulation state lives in `<game_root>/scripts/logic/` so it can be stepped
  without a scene.
- Exchange `GameConfig.fingerprint()` at handshake and refuse a mismatch. Divergent
  tuning is a desync that otherwise surfaces much later as inexplicable behaviour.
