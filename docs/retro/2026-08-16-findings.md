`python tools/plan_html.py` was rerun 6, 3, 4 and then 11 times across four
sessions while the agent iterated proposal.json toward something the gate and
the human would both accept. S24:H10 ("Your plan is significantly lacking...
Are we saying in this plan that that is not being affected?") and S20:H8

the schema and print what is wrong before regenerating, so the agent (and the
human) sees the failure reason without a regenerate-and-reread cycle each time.

happening." (S20:H2) and "I'm seeing a lot of unproposed functions here...
